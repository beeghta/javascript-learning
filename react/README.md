# Neuron Dashboard — React

A React frontend for the Neuron API built with Node.js and Express.

## Features

* Fetch neurons from REST API
* Display neurons using React components
* Conditional rendering based on activity
* React state management with `useState`
* Side effects with `useEffect`
* Controlled form inputs
* Client-side form validation
* Add neurons with POST
* Update neuron activity with PUT
* Delete neurons with DELETE
* Loading states for API operations
* Error handling
* Per-neuron update/delete loading states

## Backend API

The frontend communicates with the local Neuron API:


http://localhost:3000/api/v1/neurons

**Backend:**
Node.js
Express
SQLite
