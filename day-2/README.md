#### Project

Neuron Analyzer v2

In this project, I improved the Day 1 neuron analyzer by using a reusable neuron analysis system using modern JavaScript features and ES Modules.

# 

#### The program:

* Identifies firing neurons based on their membrane potential and threshold
* Extracts the names of firing neurons
* Calculates the total firing potential
* Determines the firing status of each neuron
* Uses reusable functions for neuron analysis
* Separates functions from application logic using ES Modules
* Uses filter(), map(), find(), and reduce()
* Uses destructuring and template literals
* Uses Spread and Rest syntax
* Uses optional chaining and nullish coalescing
